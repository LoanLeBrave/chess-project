# chess-project 2026

## Documentation (Docusaurus)

Le dossier `docs/` contient la documentation interactive du projet.

### Lancement de la documentation
Pour lancer la documentation en local, exécutez les commandes suivantes :

```bash
cd docs
npm install
npm run start
```

La documentation sera accessible à l'adresse suivante : [http://localhost:3000](http://localhost:3000)
